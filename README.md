# Clustifle's FEH Rerun Tracker

Public Fire Emblem Heroes rerun tracker with General, Remix, and Monthly Revival schedules, portrait imports, blessing tags, and owner-managed entries.

## Migration in progress

This repository contains the complete original application source plus an export of 16 heroes and 16 portraits in migration-data/. The original app uses Cloudflare D1/R2 and ChatGPT authentication. A GitHub Pages frontend with Supabase storage, database, and independent owner login is being prepared.

The live original remains at https://feh-rerun-ledger.clustifle.chatgpt.site .

No credentials or owner passwords are included. Keep Supabase service-role keys and database passwords out of this repository.

Artwork belongs to Nintendo / INTELLIGENT SYSTEMS. This is an unofficial fan tracker.
