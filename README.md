## Game information

**[Fire Emblem Heroes](https://fire-emblem-heroes.com/)** is Nintendo and INTELLIGENT SYSTEMS’ mobile tactical role-playing game. Summon heroes from across the Fire Emblem series, build teams, and take part in turn-based battles and events.

I made this fan website as my personal resource tool project that records summoning banners, hero rerun windows, and New Heroes and Hall of Forms revivals. Check in-game announcements for confirmed event dates, featured heroes, and summoning availability.
