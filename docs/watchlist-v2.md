# My Watchlist in version 2.0

My Watchlist replaces the Personal tracking section. Add a hero from its profile using **Add to my watchlist**, then use My Watchlist to browse saved heroes, organize collections, and check recorded reruns.

The beta includes saved hero cards, search, collection filters, next-rerun/name sorting, collection editing, removal, and a profile shortcut. Banner Archive is removed; recorded appearances remain in individual hero profiles.

Before public release:

- Import existing Personal tracking followed heroes into each account's watchlist without duplicates, preserving existing watchlist collections.
- Retain saved schedule bookmarks in a separate subsection of My Watchlist, or obtain a decision about their replacement before retiring that data.
- Verify account privacy and ownership for all users; beta currently permits Head Admin testing only.
- Keep waitlist placements clearly uncertain and show only recorded reruns.

The beta does not migrate or delete production personal-tracking data.
