# v3.5 — Final feature release

Version 3.5 includes the v3.4 design and quality pass and closes the major feature roadmap. Schedule and roster maintenance continues, along with fixes described in the [maintenance policy](../MAINTENANCE.md).

## Included features

- Schedule and waitlist browsing, image exports, and shared portrait presentation.
- Release and game-origin directory sorting, origin filters, and portrait-only sizes through Extra large.
- Compact personal profiles, watchlists, collections, saved schedules, and saved display choices.
- Forum discussions and drafts, with automatic connection recovery when a valid provider token is available.
- Staff workflows for heroes, skills, banners, revivals, waitlists, versions, content, and access management.

## Final quality work

Keyboard navigation, focus visibility, mobile dialogs, lazy-loaded tools, portrait failure recovery, and help/credits are finalized in [v3.4 notes](release-v3.4.md). Page and workflow coverage, verification results, and remaining limitations are recorded in [release validation](release-v3.5-validation.md).

No database migration or account-data reset is included. Revoked GitHub access still needs the account holder's authorization. External service availability and manually entered schedule accuracy remain outside automated UI validation.
