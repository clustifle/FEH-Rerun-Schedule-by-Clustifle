# FEH Rerun Tracker source backup

The source folder contains the current application and uploaded design assets. The data folder contains the public hero records and portrait files exported from the live website.

No credentials, local database files, dependencies, or build output are included.

This backup is not yet a GitHub Pages deployment: the current application requires a Cloudflare-compatible server, D1 database, R2 portrait storage, and ChatGPT owner authentication. A GitHub Pages version needs static data with GitHub-managed edits, or a separate backend and replacement owner authentication.

Existing .openai/hosting.json is reference configuration for the original Sites deployment; it does not deploy to GitHub Pages.
